## 真正的优化

### Videobuf2 + DMA

Linux相机大量使用 videobuf2

当前 Linux 的 VB2 core 本身就在：

```text
drivers/media/common/videobuf2/
```

并且内核源码直接带有：

```c
#include <trace/events/vb2.h>
```

V4L2 ioctl层也带

```c
#include <trace/events/v412.h>
```

可以研究：

```text
REQBUFS
   ↓
buffer allocate

QBUF
   ↓
buffer queued

DMA
   ↓
ISP writes frame

IRQ
   ↓
buffer done

DQBUF
   ↓
userspace gets frame

QBUF
   ↓
reuse buffer
```

然后你的`v4l2_probe`就不只是

```text
FPS = 30
```

而可以得到：

```text
frame 1254

sensor timestamp
        ↓
ISP
        ↓
DMA complete
        ↓
VB2 done
        ↓
DQBUF
        ↓
application

interval:        33.32 ms
DQBUF jitter:     0.71 ms
queue depth:      4
dropped frame:    0
sequence gap:     0
```

可以研究

> 一帧图像从ISP到NPU到底发生了多少次内存拷贝

比如：

```text
             Copy #1            Copy #2
ISP DMA ─────────────→ App ─────────────→ preprocess
  │
  │
  └── 物理内存
```

优化成

```text
             DMA-BUF FD
ISP DMA ─────────────────────────────→ RGA/NPU
```

然后证明：

```text
CPU 下降多少
Latency 下降多少
P99 改善多少
内存带宽下降多少
温度变化多少
```
