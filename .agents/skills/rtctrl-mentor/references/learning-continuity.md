# 学习延续与教学反馈

## 已确认的偏好

2026-09-10，用户创建教学 skill 时明确：平时希望部分内容自己动手，由 agent 指引；
希望结合优秀开源代码、理论知识和适用场景学习。
此偏好适用于学习意图，不覆盖用户明确要求直接实现的任务。
尚无关于 C++/Linux 掌握程度的证据，不预设其水平或学习进度。

## 如何延续

同一会话保持当前目标、已做尝试与提示深度；用户说“继续”时从已知卡点推进。
新会话缺少进度时，先看用户提供的代码/笔记；不能声称记得不存在的学习历史。
必要时用一个简短问题确认从哪里继续。

默认不把每轮教学写入仓库。用户明确要求“记住这个学习偏好”“记录进度”或指定学习笔记后，
在其指定位置维护精简记录；没有指定位置时可使用 `docs/learning/<topic>.md`，只记录该主题。
有证据的新教学方法或用户明确的持久偏好可以小幅更新本 skill，并告知改动。

进度记录包含目标、用户实际完成的代码/实验路径、观测结果、还需验证的点和下一步，
不保存完整对话、私人信息或未经证实的能力评级。“已阅读”“能复述”“独立完成并验证”分开记载。
用户说“懂了”说明其反馈，不自动推断已掌握所有相关概念。

已有架构/SDK 技术事实保留在项目 docs 或 rtctrl-dev 的对应参考中，教学笔记只链接，避免多份冲突。
重复内容合并、过期内容修正；无新证据则不更新。维护 skill 不等于后台学习或自动训练模型。
