# SysRq 日志刷新 RCU 上下文修正与板测

延续用户授权的源码 Linux 移植；本阶段只修复已观察到的 SysRq 复位日志等待缺陷。

1. 重查串口、Android/root/电量、Wi-Fi链路和ADB；运行状态不继承旧记录。
2. 基于锁定树追踪 SysRq 外层 RCU 读锁、kmsg_dump 与 pr_flush。
   在真实 pr_flush/pr_msleep 函数回归中覆盖有日志积压的 RCU、普通进程、原子/softirq和零超时。
3. 最小补丁只排除 RCU 读侧睡眠，沿用现有非睡眠等待分支和原超时语义；不修改电源/MCU接口。
4. 新 Image 使用相同配置、原两补丁及新补丁；所有输入摘要和原输出分开保留。
5. RAM 上板，验证 PID1/基础驱动和源码程序；完整清理后用同样 SysRq 复位路径返回 Android。
   保留完整复位串口流，检查 RCU/其他告警及五个启动分区SHA。

普通重启、关机、电源轨、MCU ACK和运动不由本阶段推定通过。
若连接或传输受阻，保留实际失败条件，继续完成独立可验证的源码与构建工作。
